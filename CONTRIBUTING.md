# Bijdragen

Bijdragen zijn welkom.

## Werkwijze

1. Fork de repository.
2. Maak een aparte branch voor je wijziging.
3. Houd wijzigingen klein en gericht.
4. Test de installer en backupflow op Windows 10 of 11.
5. Controleer dat bestaande configuraties niet worden overschreven zonder duidelijke reden.
6. Open een pull request met een korte uitleg van het probleem, de oplossing en hoe je hebt getest.

## Richtlijnen

- Gebruik duidelijke PowerShell-namen en foutmeldingen.
- Voeg geen wachtwoorden, tokens, persoonlijke paden of andere geheimen toe aan commits.
- Behoud ondersteuning voor zowel lokale paden als UNC/netwerkpaden.
- Een tijdelijk onbereikbaar backupdoel hoort geen corrupte backup of permanente fouttoestand te veroorzaken.
- Wijzigingen aan statuswaarden of configvelden moeten ook in de README en CHANGELOG worden beschreven.

## Bugs en feature requests

Gebruik de GitHub issue templates zodat reproduceerstappen, Windows-versie en relevante logregels direct beschikbaar zijn.
