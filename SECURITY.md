# Security Policy

## Supported versions

Beveiligingsfixes worden toegepast op de meest recente versie op de `main` branch.

## Een kwetsbaarheid melden

Meld beveiligingsproblemen niet als openbaar issue wanneer daarbij tokens, credentials, privé-repositorygegevens of andere gevoelige informatie betrokken zijn.

Gebruik bij voorkeur GitHub's **Private vulnerability reporting** / Security Advisory-functie voor deze repository wanneer die beschikbaar is. Als dat niet beschikbaar is, neem rechtstreeks contact op met de maintainer via het GitHub-profiel van Techraym zonder gevoelige details publiek te plaatsen.

Vermeld waar mogelijk:

- de getroffen versie of commit;
- Windows-versie en PowerShell-versie;
- een minimale reproductie;
- mogelijke impact;
- voorgestelde mitigatie, indien bekend.

## Gevoelige gegevens

De tool hoort nooit GitHub-tokens, wachtwoorden of andere credentials naar de backupmap of logs te schrijven. Meld het direct wanneer je gedrag ziet dat hiervan afwijkt.
